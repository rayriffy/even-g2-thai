## Compact font and artifact

The old 133,018-byte A4 font plus code exceeds this version's install window.
The user selected smaller bitmaps while retaining all characters and sizes.
Compact storage keeps eight 132-entry metric tables in 8-byte records, plus
half-resolution A2 samples packed four per byte. The source font and thin
setting are unchanged. Max pooling retains significant thin strokes and the
separate SARA AM dot, which average pooling erased at small sizes.

Four alpha levels expand directly into caller-owned A8 buffers at full glyph
dimensions; no additional heap or bitmap scratch buffer is needed. Advances,
dimensions and ordinary offsets are preserved. Contextual tone alternates
are raised against actual compact pixels; diagnostic raster line boxes are
recomputed. Stock font selection, bounded SRAM cache and immutable fallback
on allocation failure remain intact. Edges are coarser than the old A4 build.
